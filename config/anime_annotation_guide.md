# 二次元标注批次说明

## 标注顺序

1. 先判断 `risk_level`。
2. 再标 `violence_type`、`injury_detail`、`quality`。
3. 补 `style_domain` 和 `scene_context`。
4. 备注写可见依据，重点说明为什么不是更高或更低风险。

## 风险口径

- `L0_安全`：没有平台明确禁止的色情、暴力血腥、虐待等实刻画内容。
- `L1_轻微违规`：轻度暴力、少量血迹、轻度武器威胁等，通常限流。
- `L2_中度违规`：明显暴力、开放性伤口、较明确威胁等。
- `L3_严重违规`：极端血腥、肢解、虐杀、严重虐待等。
- `X_无法判定`：图本身不可辨，不能因为风格暗黑或猎奇就选 X。

暗黑、猎奇、压抑、惊悚、夸张表情本身不等于暴力血腥。只有画面存在实际的
伤害、流血、肢解、虐待、明确攻击或武器指向关系时才进入相应违规等级。

## 暴力类型

- `无暴力` 表示没有正在发生的攻击行为，可以与血腥后果、暗示威胁共存。
- `直接暴力（攻击进行中）` 需要有正在发生的攻击动作。
- `后果展示（尸体/伤口）` 需要有尸体、伤口、血迹等后果。
- `暗示/威胁（武器指向/捆绑）` 需要有指向对象、攻击姿态或强制束缚关系；
  单纯持刀站立、刀尖朝地、商品展示不算明确威胁。

## 图像质量

quality 可多选。文字扭曲、遮挡或严重模糊只表示内容可靠性下降，不自动等于违规。

## 风格与语境

`style_domain` 和 `scene_context` 是附加训练标签，不替代现有四任务标签。
动画战斗 pose、影视虚构、游戏截图等语境要写清楚。

## 导入 Label Studio

1. 新建 Image Classification / Object Detection 项目。
2. 在 Labeling Interface 中粘贴 `labelstudio_config.xml`。
3. 将 `images/` 中的图片作为本地文件导入，或按任务清单逐张上传。
4. 导出 JSON 时保留原始任务名，便于和 `annotation_manifest.csv` 对齐。
