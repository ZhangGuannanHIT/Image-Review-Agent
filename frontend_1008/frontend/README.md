# ImageGuard 展示页与图片审核工作台

原生 HTML/CSS/JavaScript，无构建步骤。启动后端后访问 http://localhost:8000/；默认进入图片审核工作台，通过左上角 ImageGuard 或右上角说明弹窗进入同一文档内的项目展示页。直接打开 index.html 可以使用本地选图预览并浏览展示页，但不能提交审核请求。

展示页与工作台使用 `#home` 和 `#workspace` 切换，不重新加载文档。工作台右上角问号按钮提供简要使用说明，其中“查看项目详细介绍”会打开展示页顶部；点击工作台左上角 ImageGuard 也可回到展示页。再次进入工作台时，页面内的图片和结果仍然保留。桌面端侧栏可完全收起，移动端使用覆盖式抽屉，展开/收起按钮提供随状态变化的悬浮说明。

## 使用流程

右侧初始展示说明。点击上传、将图片拖入右侧工作区，或直接粘贴剪贴板中的图片，确认预览后开始审核。工作区追加图片和等待状态，随后原样展示后端审核建议与编号。完成后可继续提交下一张，每次审核独立，不传递其他图片或结果，也没有文本输入。

左侧“工作区”列表可以新建分组、切换旧组。右键点击工作区，或点击该条目旁的“⋯”（适合触屏和键盘），可打开重命名和删除操作。重命名与删除确认均使用页面中央弹窗；删除当前或最后一个工作区后会自动切换或创建一个空工作区。每组分别保存自己的图片和审核结果，页面展示序号从每个工作区的 01 开始。“当前工作区的审核记录”旁数字是该组提交的图片张数。失败、取消或超时的记录保留并支持重新审核；重试更新该图片的显示结果，后端会生成新的审核编号。复制成功会在操作位置直接反馈。

## 留存与状态

- 各工作区及其图片 Blob、预览 URL、审核结果与提交时间仅存在页面内存中。
- 图片、工作区和审核结果不写入浏览器持久存储，刷新或关闭后清空；localStorage 只保存主题与桌面侧栏偏好。
- “新建工作区”创建一个新的分组，旧组仍可切回；“清空当前工作区记录”只清空当前组，不影响其他组。
- 点击右上角外观图标会展开三个中文选项：跟随系统、日间和夜间；当前选项具有明确的高亮状态。外观偏好写入本地浏览器，刷新后继续使用；图片、审核结果和工作区仍不会持久化。
- 清空、换图和卸载时释放预览 URL。清空和取消会中止前端等待，后台任务及日志可能仍然存在。
- 每次只允许一个审核请求。新请求、取消与重置使用请求对象隔离，旧响应不会覆盖当前记录。
- 健康检查超时为 5 秒，审核等待超时为 120 秒。
- JPG/PNG/WEBP，单张不超过 10MB；后端校验为最终依据。
- Mock 标志固定显示在顶部，每条记录保留提交时的模式标记。

## 接口

仅使用 GET /health 和 POST /api/review。审核上传字段为 image，成功响应为 {id, suggestion}，错误响应读取 code、message、id。不推测风险等级或工具调用轨迹。

在项目根目录运行 node tests/frontend-flow.cjs，需要 Playwright 和本机 Edge。可通过 NODE_PATH 指定已安装的 Playwright 包目录，不需要安装前端运行依赖。
