# ImageGuard

面向真实照片、二次元插画和游戏画面的图像内容审核系统。结合训练后的 FG-CLIP2、多维分类头、文字识别、规则检索和条件式视觉复核，生成审核结论，并提供持久化审核工作台。

## 技术栈

| 层次 | 技术与职责 |
| --- | --- |
| 基础视觉识别 | FG-CLIP2、PyTorch、Transformers、PEFT LoRA，提取图像特征并完成多任务分类 |
| 专项识别 | 二元血腥分类头、图像质量融合头、基于冻结 CLIP 特征的动漫风格路由器 |
| 图像处理与文字检测 | Pillow、OpenCV，完成图片处理、低层特征分析和轻量文字检测；支持可选 RapidOCR 检测器 |
| OCR | 本地 GLM-OCR HTTP 服务；保留阿里云 OCR 与云端 GLM-OCR 适配器 |
| 大模型接入 | LangChain Core、langchain-openai、OpenAI 兼容接口，用于文字语义判断、结构化视觉证据复核和审核解释 |
| 规则检索 | 字符 2–4 gram TF-IDF 与本地 JSON 知识库，检索规则及案例 |
| 审核编排 | Python 固定条件工作流与程序策略，按证据触发工具并确定最终动作 |
| 后端服务 | FastAPI、Uvicorn、Pydantic，提供图片审核、记录查询、反馈与导出接口 |
| 数据存储 | SQLite 持久化审核记录，JSONL 保存审计日志，本地文件保存审核原图 |
| 前端 | HTML、CSS、原生 JavaScript，构建审核队列、证据展示和人工调整界面 |

## 核心功能

### 多维图像识别

以训练后的 FG-CLIP2 为基础，输出风险等级、暴力类型、血腥程度和图像质量信息。暴力类型与图像质量支持多标签；二元血腥头、质量融合头和场景语义相似度提供补充证据。

保留原始风险 `risk_raw`，由程序结合专项模型、文字和场景证据计算 `effective_risk`，区分模型原始预测与最终采用的风险等级。

### 文字识别与语义审核

先检测图片是否包含文字，再按条件调用 OCR。识别文本进入本地规则检索、文字语义判断和窄范围威胁规则核验。

文字违规判断检查引用是否来自 OCR 原文，并结合对象、伤害行为及表达语境，区分明确威胁与普通描述。

### 动漫与游戏画面复核

通过动漫风格路由和游戏 UI 场景候选筛选需要进一步核验的图片。视觉模型以结构化字段描述可见伤害、攻击、威胁、武器关系和场景语境，程序再据此调整审核动作。

持有武器、战斗姿势、红色装饰和技能特效分别判断，避免仅凭单一外观认定违规。当前默认启用动漫与游戏候选复核，真实照片语境自动放行路由默认关闭。

### 条件式审核与结果解释

工作流以 CLIP 分析为必要步骤，按条件执行文字检测、OCR、规则检索、场景匹配和视觉复核；工具耗时、跳过原因及失败状态纳入审核记录。

程序策略支持放行、限流、人工复核和下架。默认放行与限流采用程序模板，人工复核与下架按条件调用 LLM 生成解释，解释校验失败时回退到程序模板。

### 持久化审核工作台

- 按工作区组织审核队列，支持真实与虚拟图片域、审核动作及风险筛选。
- 支持多图和文件夹导入后的串行审核。
- 分组展示基础分类头、专项模型与场景、文字与规则、最终策略证据。
- 展示原始风险、有效风险、审核动作、分阶段耗时与原始结构化结果。
- 支持确认系统建议、人工升级或降级调整、填写反馈原因及再次调整。
- 支持历史记录查询、原图查看、工作区记录清理和 CSV 导出。

### 训练与评估工具

提供分类模型训练、动漫风格路由训练、标注批次整理、Label Studio 标注导入，以及审核策略、OCR、文字检测和动漫样本评估脚本，用于模型开发与策略比较。
